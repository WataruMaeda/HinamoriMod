# 雛森桃・戦闘キャラクター画像 共通制作規格

この文書は今後の idle / attack / defense / kido および追加アニメーション画像の制作・加工・出力に適用する。

## 基準
- 基準画像: `HinamoriMod/images/character/idle_00.png`。**ピクセルサイズだけでなく、画像内の人物の見た目の大きさもこの画像に揃える。**
- キャンバス: **439 × 439 px**、透過 **RGBA PNG**。
- 足元: キャンバスの **Y ≈ 416 px** に揃える。
- キャラクターの描画高: 基準画像で **約405 px**（ポーズで多少変わるため、顔・頭身・胴体の見かけのサイズも目視比較する）。
- キャラクターを縦横別倍率で引き伸ばさない。**アスペクト比維持**。
- アニメーションの全フレームに **同一の縮尺** を適用する。フレームごとに人物が拡大縮小しないようにする。
- 髪飾り・刀・炎・鬼道などのエフェクトは人物本体とは区別して扱い、必要な余白を残す。エフェクト端がキャンバスから切れないようにする。
- **余白込みの画像サイズだけを合わせて完了としない**。人物の身長・足元・頭部の見かけの位置を待機画像と比較する。
- 出力時に各フレームのサイズ・RGBA・足元・人物サイズを確認し、プレビューを作成する。

## Godotでの表示
`HinamoriMod/scenes/hinamori_idle.tscn` の `AnimatedSprite2D` は現在 `centered = true`, `position = Vector2(0, -135.75)`, `scale = Vector2(0.75, 0.75)`。画像の中心・足元がずれると戦闘画面で上下に飛ぶため、画像側で位置を揃える。

## 注意
- 439×439・Y=416・人物高約405は **idle_00.png に基づく基準**。厳密な足元や人物の境界はフレームごとに確認する。
- 新規モーションでエフェクトが大きく、439×439に収めると人物が小さくなる場合は、勝手に縮小せずユーザーに確認する。
- PNGはゲーム素材。**背景の黒色を描き込まず、透過を維持する**。
