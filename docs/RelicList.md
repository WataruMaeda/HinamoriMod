### 実装メモ

- `TobiumeEmber` は `AfterSideTurnEnd` を使って火種を付与。コールバック署名・発動タイミングを要ビルド／実ゲーム検証。
- `FlameTalisman` は `AfterRoomEntered` で敵全体へ `BurnPower` を付与。敵の生成タイミングに依存するため要実ゲーム検証。
- `TobiumeGuard` は `AfterRoomEntered` で `CombatRoom` を判定し、`EmberCmd.GainEmber(10m, Owner)` を呼ぶ。戦闘開始時の実際の発火タイミング、火種の表示、飛梅生成の副作用をゲームで要検証。
- **新規9個すべてにC#クラスと日英テキストを追加済み**。うち6個は効果のフック未接続でゲーム上は未実装。専用レリックのアイコン画像は未追加。レリックプールへの登録・表示も未検証。
- 詠唱消費累計、ターン最初の鬼道判定、状態異常カードの抽選、手札選択UIは別途実装が必要。
- エンシェント追加獲得は五番隊副官章に分離済み。

### 残タスク：効果のゲーム連携（2026-11-20）

**重要：下記6個はクラス・補助メソッド・ローカライズを用意した段階で、レリック効果はまだ発動しない。完成扱いにしない。**

- [ ] **残火の欠片** `LastEmberFragment.cs`：火傷付与の共通経路に `AdjustBurnAmount` を接続し、1回の付与につき+1を適用。再帰・他キャラへの影響を防ぐ。
- [ ] **鬼道の護符** `KidoTalisman.cs`：`HinamoriModCard.SpendChant` から実消費量を通知し、`CountBlockTriggers` の閾値到達時にブロック10を付与。戦闘開始リセットとリプレイ除外を検証。
- [ ] **鬼道の手引き** `KidoPrimer.cs`：初期ドロー後に専用カード候補3枚（重複なし）を提示、1枚生成して手札に追加、手札から1枚選択して捨てる。選択UI・マルチプレイ同期を実装。
- [ ] **火傷の呪印** `BurnCurseMark.cs`：攻撃者に火傷がある場合の被ダメージ乗算フックを接続。暫定0.8倍（追加20%軽減）の最終数値を確認。
- [ ] **鬼道の秘伝書** `KidoSecretManual.cs`：ターン開始時に使用済み状態をリセット。破道・縛道の最初の1枚のみ `EffectiveChantCost` と `SpendChant` の両方を0にし、実使用後に消費。リプレイ対応。
- [ ] **禁術の代償** `ForbiddenArtsPrice.cs`：毎ターンEN+1の実付与と、ランダムな状態異常カード1枚の手札生成を接続。候補プール・手札上限・状態異常の即時効果を検証。
- [ ] **共通**：9個のレリック画像（通常・輪郭・大）追加、プール登録の検証、ビルド、実ゲーム動作確認。
- [ ] **既存3個**：`TobiumeGuard`、`TobiumeEmber`、`FlameTalisman` のイベント発動順・効果を実ゲームで確認。
- [ ] **初期レリック**：副官章の画像、初期2個所持、各Actの追加獲得、強化交換時の保持を検証。
